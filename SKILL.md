# Maagarim Reader plugin

Three skills in one plugin:

| Skill | Use for |
|-------|---------|
| **[maagarim-reader](skills/maagarim-reader/SKILL.md)** | Mishnah / Tosefta / Bavli / Yerushalmi vs [Maagarim](https://maagarim.hebrew-academy.org.il) |
| **[tanakh-nikud](skills/tanakh-nikud/SKILL.md)** | Tanakh quotes → nikud without te'amim via [Sefaria](https://www.sefaria.org) |
| **[feedback](skills/feedback/SKILL.md)** | Report a problem or unclear result (דיווח) — structured email to maintainer |

**Cursor:** copy each `skills/<name>/SKILL.md` to `.cursor/skills/<name>/`, then `@maagarim-reader`, `@tanakh-nikud`, or `@feedback`.
